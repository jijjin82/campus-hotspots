- 도서관
- 운동장
- 채플 (예수성심성당)

🔗 웹사이트: https://jijjin82.github.io/campus-hotspots/


## 3주차: 네 페이지, 네 가지 분위기

- GitHub Pages URL: https://jijjin82.github.io/campus-hotspots/

### 페이지별 스타일
- 프론트페이지: 여행 잡지 느낌 / `page-home` 클래스, 흰 배경(#ffffff)에 큰 제목(2.6rem)과 밑줄 포인트를 준 카드
- 장소 1 (중앙도서관): 조용한 서재 느낌 / `page-library` 클래스, 크림색 배경(#faf3e6)과 세리프 글꼴, 얇은 갈색 테두리
- 장소 2 (운동장): 활기찬 야외 느낌 / `page-playground` 클래스, 하늘색 배경(#eaf4fc)과 둥글고 큰 카드(border-radius 28px), 파란색 버튼
- 장소 3 (채플): 고요한 밤 느낌 / `page-chapel` 클래스, 남색 배경(#202235)과 금색(#ffd166) 

### 모바일 스타일
- 적용한 @media 조건: `@media (max-width: 600px)`
- 모바일에서 특별히 바뀌는 부분과 이유: 카드 여백을 줄여 스크롤을 짧게 했고, 제목 글자 크기를 줄여 화면을 넘치지 않는다. 
- 휴대전화에서 네 페이지를 확인한 결과: 네 페이지 모두 가로 스크롤 없이 세로로 잘 쌓였음.
- 모바일에서 편안하게 보이기 위해 클릭 버튼을 중앙에 위치하게 했음.
